# SkyDeck.ai Personal Tool for AI-Driven Development

Welcome to the SkyDeck.ai Personal Tool repository! This repository contains a collection of JSON files used for various AI-driven development tasks.

## Contents

- **Templates**: JSON files for code generation templates.
- **Configurations**: JSON files for tool configuration and settings.
- **Data**: JSON files containing sample data for testing and development purposes.

## Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/skydeck-ai-tool.git
    cd skydeck-ai-tool
    ```

2. Explore the folders to find the JSON files you need.
